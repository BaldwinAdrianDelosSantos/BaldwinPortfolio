# Baldwin Adrian Delos Santos | Advanced Portfolio

A modern, animated portfolio website built with HTML, CSS, and vanilla JavaScript.

## Features

- Particle network background animation
- Custom cursor with follower effect
- Smooth scroll animations
- Typewriter effect
- Animated skill progress bars
- Project filtering system
- 3D tilt effects on project cards
- Stats counter animation
- Dark/Light theme toggle
- Mobile responsive design
- Glassmorphism UI components
- Scroll progress indicator
- Magnetic button effects

## Quick Start

1. Open `index.html` in your browser, or
2. Serve with XAMPP at `http://localhost/myportfolio/`

## Customization

### Update Personal Information

Edit the following sections in `index.html`:

- Hero section: name, title, description
- About section: biography
- Skills: adjust progress percentages
- Projects: update with your real GitHub links
- Contact: update email and social links

### Change Colors

Modify CSS variables in `css/style.css`:

```css
:root {
  --accent: #00d4ff;
  --accent-secondary: #7c3aed;
  /* ... other colors */
}
```

### Add Your CV

Replace the download CV button link with your actual PDF file path:

```html
<a href="path/to/your-resume.pdf" download class="btn btn-secondary">
```
